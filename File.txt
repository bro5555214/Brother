OverviewREST APIMCPOAuth
API reference
A REST API to drive your account: create and manage deployments, files, backups, packages and environment variables.
Public beta. Endpoints and responses may still change, and every call acts on your real deployments.
Base URL
https://bot-hosting.net/api/v172
endpoints, 3 categoriesManage API keys
curlPythonNode.js
Authentication
Every request needs an API key, passed as a Bearer token. Create and manage keys from your developer settings.
Scopes
A key is limited to the scopes you grant it. A request is allowed only if the key holds the endpoint's scope and you have permission on the target resource.
Deployments
• deployments:readList and inspect deployments
• deployments:powerStart, stop, restart, console
• deployments:writeCreate, edit, delete, resize, move
• deployments:shellRun shell commands in a container
• projects:readList your projects
• projects:writeCreate and delete projects
• files:readBrowse and download files
• files:writeUpload, edit, rename, delete files
• env:readRead env vars, secrets masked
• env:writeSet env vars
• backups:readList restore points
• backups:writeTake, restore, delete restore points
• packages:readView installed packages
• packages:writeAdd and remove packages
Account
• account:readRead profile and quota
• billing:readRead invoices and plan
• credits:spendSpend credits to create resources
Templates and docs
• templates:readBrowse public templates
• docs:readSearch and read the docs
Rate limits
120 requests per minute per key, on a sliding 60-second window, and 300 per user across all their keys. Every response carries the remaining budget in X-RateLimit-Remaining; going over returns 429 with a Retry-After header.
Deployment state
Read live from the node on every request, so it reflects what your bot is doing right now. Not to be confused with status, the billing lifecycle.
state	Meaning
running	Up and serving right now.
starting	Boot requested, container not up yet.
stopping	Shutdown in progress.
offline	Installed but not running: stopped, crashed, or out of resources.
installing	Created and being provisioned; it has never run yet.
unknown	Its node could not be reached. Retry shortly.
Networking
Every deployment carries the node it runs on and the ports it publishes. To reach a service from outside, connect to node.fqdn:port.
Field	Meaning
node	The node hosting it (name, fqdn and region). null until it is placed on a node.
port	The primary published port. null if none is published yet.
ports	Every published port, primary first.
Access and sharing
list and get return both the deployments you own and those shared with you. Three fields tell them apart.
Field	Meaning
owned	true if you own it, false if it was shared with you.
owner	Who owns it (id and username). Always present.
shared	Collaborators, each with their granular permissions (OVERVIEW, CONSOLE, FILES, ADMINISTRATOR and more). Empty if not shared.

deployments.check
GET/deployments/:id/checkdeployments:read
Request this deployment over its public URL and report what came back. Use it after deploying or fixing a site to confirm it really works - "the logs say it started" is not the same as "the page loads". Returns the HTTP status and the start of the body, so a 500 or a stack trace is visible. Server-rendered output only: no JavaScript runs. Any method: POST a JSON body to test an API route. On a 2xx HTML page it also requests the first same-origin links and assets it finds (links) and names the broken ones and duplicated nav entries in note. It goes through the public URL, the way a visitor does. To hit many routes at once or load-test, one deployments.shell command with a curl loop on localhost:$SERVER_PORT is cheaper than one check per URL. To ask what is wrong with a deployment rather than what one URL returns, call deployments.diagnose instead: it answers this plus the state, the logs and the startup config in one call.
RequestCopy
curl "
https://bot-hosting.net/api/v1/deployments/dep_a1b2c3d4/check?path=%2Fmain.py&method=GET&body=string&headers=string
" \ -H "Authorization: Bearer bhk_your_key"
ResponseCopy
{ "url": "
https://.../files/download?path=%2Fmain.py
", "status": 1, "ok": true, "contentType": "string", "title": "string", "body": "string", "error": "string", "hint": "string", "links": [ { "path": "/main.py", "status": 1 } ], "note": "string" }
